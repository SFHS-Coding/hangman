# Hangman
*Put your hangman project here!*

## Objectives

You should build a functional program that does the following: 
- Assigns the user a random word.
- Gives the user limited opportunities to guess the word.
- Reveals correct letters as the user guesses them. 
- Reveals the word after the user either a) guesses it correctly or b) uses all their guesses.

Your program should be easy to use, readable, and all-around pleasant for the end user (good UX)

## Bonus Points

If you want to earn bonus points, you can use a bank of different words and assign the user one to guess at random. 

## Hints

Remember, the user doesn't need to see all variables! Some can be only on the back-end.
